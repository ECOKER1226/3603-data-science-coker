# 🏗️ Module 05: Foundations

- This module covered the foundational Jupyter/IPython tooling, including magic commands, shortcuts and workflow, help and documentation, Markdown and formatting, files and paths, data formats, plotting, and timing and performance.
- What finally clicked for me in this module was how much more efficient workflow becomes when using Jupyter shortcuts.
- One concept that was worth revisiting was knowing what can go wrong when converting data formats.
- As for what I would do differently, this module was straightforward and engaging as is, so I wouldn't change anything about it.
